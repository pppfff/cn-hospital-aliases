# 研究中心别名归一口径

目标是将同一研究中心的中文名称、英文名称、简称和曾用名映射到同一个官方备案
机构，而不是建立临床试验数量排行榜。以2026-09-05保存的NMPA/CFDI药物临床
试验机构备案公开列表为基准；本轮使用已校验缓存，未重新刷新线上备案状态。

## 三层数据

1. 官方机构表：仅包含备案机构，备案名称按原文逐字保留，主键由备案系统机构ID
   派生；备案号另存，不将自定义ID或ROR当成官方备案号。
2. 已确认别名表：每个名称关系带来源、类别和已知有效年代。备案字段中括号内的
   医学院、研究所、院区或互联网医院等并列文字不自动拆成别名，必须有独立的
   官方来源审核；同一个别名如果
   对应多个机构，返回歧义，不挑选第一条。保留院区限定，不推断托管关系。
3. 待审候选表：仅ROR支持的英文名/别名以及后续业务输入中的未匹配名称，必须
   取得充分证据才能进入已确认别名表。当前导出的候选表来自已关联机构的ROR
   名称，不代表已收集到所有试验平台或业务文件中的名称变体。

英文、简称、曾用名或统一社会信用代码没有全部补齐，不影响一条已有证据的
别名关系进入映射表。“五类字段齐全”和“别名可以准确归一”是不同的指标。
试验数量可以用于审核优先级，但不再限制前1,000家，也不是建库前置条件。

## 本轮结果和校验

### 中文身份优先，英文独立暂缓

已对固定备案快照全部2,039条中文机构名称、备案编号及来源逐条对账；新增
`institution_confirmation_register.csv`和`institution_confirmation_summary.json`。
62家机构有已核英文名称，1,977家英文留空并标为暂缓，不影响中文备案身份保留。
这不等于全部试验中心已归一，也不证明实时备案资质。

本轮逐项审阅359条中文候选证据记录，批准248条备案明确并列的医院级名称，
111条证据记录未批准（含部分与已批准备案证据同名的重复参考记录）。逐条决定、
原备案名称及来源见`data/curated/chinese_name_decisions.json`。学院、研究所、互联网医院、
医共体、含历史标记或未分清的复合名称继续保留，未采用自动括号拆分批准规则。
随后另按南京大学、上海交大医学院官网和阜外医院年报确认3家机构的4项中文别名，
见 `data/curated/chinese_website_reviews.json`。包括苏州科技城医院两项挂牌名称、
上海儿童医学中心简称、阜外医院1994—2014年的曾用名。保留备案主名称不变，
不合并南京鼓楼医院、研究部门或国家心血管病中心等其他实体。
2026-09-06再确认南通、杭州、双流3家医院的4项名称（含南通旧挂牌名称），
详见 `chinese-review-2026-09-06.md`。其中3项来自待核队列，1项是官网新发现的曾用名。
后续找到宁波恢复原名的省卫健委批复和武汉官网精确名称依据，新增3项名称。
批复要求另办变更登记，因此未将批复日期写作旧名失效日。
正式名称断言增至2,674条，非主名称别名635条；全局待核队列699条，其中中文79条、
非中文620条。原首批清单仍有888条名称未归一，英文暂缓不将其改为已确认。
本轮56项测试、备案独立对账及笔记本检查通过；旧来源警告17项仍保留。

### 前一英文审核批次记录

后续逐条审核进度：清单审核文件累计51家机构的56条英文名称关系，正式别名增至376条，
名称断言2,415条，覆盖322家备案机构。本批追加5家机构的5条英文名称关系：青大附院、
河南省人民医院、温医大附一院、湖北省肿瘤医院、武汉大学中南医院。仅批准医院层级名称，
不合并同页实验室、科室、合作医院及其他附属医院。
清单审核文件的证据涉及固定首批1,000条清单中的106条；合并库内原有证据后，
112条具有已确认的名称关系，其中66条通过现有地点筛选，46条仍需核实地点且不填确认ID。
其余888条中，199条仅有参考线索，689条缺少已批准名称证据，不能称为验证步骤完成。
前批包含浙大一院、二院、中国医科大学附属第一医院和盛京医院。盛京医院使用2022年
医院临床研究中心工作指引的索引双语页眉；PDF正文可读，但截图失败，限制已记录。
发现另文将第一临床学院译作医院名，未据此批准学院别名。
此前天津医科大学4条名称使用大学中英文对照PDF的搜索索引文本，直接取回PDF失败；
此限制逐条记入`review_scope`。河南省肿瘤医院英文名使用2019年大学托管原始论文的
双语机构署名，只证明名称使用关系，不证明当前资质。瑞金卢湾、海南、天津空港及
医科院肿瘤深圳等独立备案机构不合并。
首批原清单已冻结，见`trial_site_review_baseline.csv`；逐行证据及下一动作见
`trial_site_verification_register.csv`，汇总及原清单哈希见`trial_site_verification_summary.json`。
该登记表的整表对账是自动化核对已有证据，不等于新增1,000次人工网页核验。
以下26条命中等数字为追加审核前的基线；最新全量输出见
`all_site_coverage_summary.json`。全部38,784个现有中心名称组已按已确认关系重算：
98个通过地点筛选，625个地点待核，38,061个未命中。这里的全量指现有CTG缓存，
不是尚未取得的NMPA参研明细。此次构建、独立对账与53项测试通过。
直辖市英文名称新增明确的 Municipality 写法，不放宽跨省市匹配规则。

### 追加审核前基线

正式表2,039条备案记录；包含主名称的名称断言2,359条，其中非主名称映射320条，
覆盖279家备案机构；仅参考证据或备案并列字段支持的998条名称留待审核。正式表不是2万多家
医院；此前混合主数据中的未归一名称组和独立ROR条目均不进入默认机构表。

校验重点：官方ID集合与备案快照完全相同、官方名称逐字一致、每条别名可追溯
且只指向备案机构、参考名称不自动批准、未知名称不创建新机构、取消备案状态
不被改写。本快照2,039条状态均为已备案；代码保留对取消备案记录的处理与测试。

已执行47项测试、`check_official_aliases.py`和默认库校验，均通过；2,039个备案
名称逐字对账一致。当前正式映射中无规范化名称歧义，另有17条旧HTTP来源警告。
检查notebook为`notebooks/official-alias-quality.ipynb`，两个代码单元已执行通过。

结构检查不能证明已穷尽别名，也不能替代当前资质核验。官网审核是字段级证据，
不自动构成对历次法人合并、院区独立备案或专业范围的确认。

已对现有ClinicalTrials.gov中国医院名称快照做只读覆盖审计：25,667个医院名称组
中，26个名称通过现有地点筛选，另有175个名称匹配但地点筛选未通过，25,466个未命中，
各组内去重试验数的加总分别为6,884、2,228和100,347；同一试验可出现在多个组中，
这些加总不是独立试验总数。未命中及地点待核结果已按组内试验数降序写入
`data/official/trial_site_alias_review_queue.csv`，仅用于后续人工审核；该快照不
代表NMPA登记平台的参研医院全集。

地点筛选未通过可能来自拼写、行政区写法或地点别名缺失，不能直接判定为真实
地理冲突。保留状态代码`matched_location_conflict`，但此类行的正式机构ID及
备案号均留空；`candidates_json`提供候选备案机构及所在地，`candidate_count`
计入这些候选。多个同名候选即使全部未通过地点筛选，仍保留为歧义供审核。
本轮49项测试通过，包括地点待核记录不自动批准及多候选保留测试。

## 使用及下一步

默认CLI或`HospitalRegistry.load_default()`执行官方备案归一，批量输出原始名称、
统一名称、机构ID、备案号及备案状态。模糊相似名称只标记为`fuzzy_candidate`，
不填写已确认机构ID。

对研究中心清单可直接运行`PYTHONPATH=src python scripts/resolve_trial_sites.py
sites.csv resolved.csv`；脚本支持中英文常见列名，保留原始行并追加官方备案字段。

构建命令：`PYTHONPATH=src python scripts/build_official_aliases.py`。
无需NMPA试验参与明细，也无需试验计数。此前排名表保留为可选分析资料，
不是正式映射库。

重跑名称覆盖审计：`PYTHONPATH=src python scripts/audit_trial_site_coverage.py`。

下一步按实际研究中心清单中的未匹配名称和使用频率审核候选；增加一个有证据
的别名后，即可重复处理业务文件验证命中率与歧义率。可接入NMPA登记、CTG或
业务Excel中的名称来扩充候选，不改变官方备案作为身份基准的原则。
