# 临床试验医院数据覆盖与质量说明

2026-09-05更新：新增2,039家官方药物临床试验备案机构底表、ROR参考关联及
前1,000条审核队列。该备案表不证明试验参与关系；NMPA公示平台试验明细仍
未取得。最新进度见[医院主数据状态](master-data-status.zh-CN.md)。

## 当前快照

- 数据源：ClinicalTrials.gov 官方 API v2。
- API 数据时间：2026-09-03T09:00:05。
- 查询条件：试验类型为 `INTERVENTIONAL`，且至少一个研究中心的国家为
  `China`。
- 查询命中：41,272 项研究。
- 带名称的中国中心事实：137,647 条。
- 保守归并后的全部中心名称组：38,784 个。
- 名称包含医院或医学中心标志的组：25,667 个。
- 同城高相似、待人工核验的名称对：46,193 对。

这里的“名称组”以“保守规范化名称 + 登记省份 + 登记城市”为键，不代表
独立法人医院数量。

## 质量信号

- 25,667 个医院名称组中，6,324 个没有填写省份。
- 17,947 个名称组只出现于一项试验。
- 1,473 个名称组出现于至少十项试验。
- 25,625 个名称组使用拉丁字符，只有 42 个包含汉字。
- 当前 6 条人工核验中文种子记录与英文登记名称没有同名同城的精确命中，
  因此不能自动建立中英文别名关系。

## 尚未覆盖

“所有临床试验参与医院”不存在一个可直接证明完整性的单一公开数据源。
当前快照尚不包括：

- 只登记在国家药监局药物临床试验登记与信息公示平台、但未登记在
  ClinicalTrials.gov 的试验；
- 只登记在中国临床试验注册中心（ChiCTR）的研究；
- 登记记录中没有公开中心名称的试验；
- 观察性研究；
- 医院名称与统一社会信用代码、医疗机构执业许可证或官方中文名称的全面
  人工核验关系。

国家药监局平台是国内药物注册性临床试验的重要权威来源。本环境未取得
可用的批量试验参与明细，检索和详情页访问返回校验页面。现已增加本地CSV
及HTML导入适配器，等待真实导出样本接入；不能因此将备案表称为全量参研表。
